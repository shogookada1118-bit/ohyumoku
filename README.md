# ohyumoku — 大夢木🌲 プロトタイプ正本

「大夢木」プロジェクトの「最初の10分」プロトタイプのソースコード一式です。
ChatGPTとPコン（Perplexity Computer）が同じ実物を直接参照して作業するための共通正本として、このリポジトリを利用します。

## 体験の概要

一本の連続したタップ体験として構成しています。

```
WHITE CANVAS
↓
ユーザーが「欲しい」と思うものが現れる
↓
触る
↓
LOCK（静寂のあと、初めて問いが現れる）
↓
ユーザーが回答・行動する
↓
UNLOCK
↓
実際に何かをGETする
↓
世界そのものが変化する
↓
初めて🌱が生まれる
```

53、守破離、F、Freedom Creator、全体マップ、進捗率などの裏側の仕組みは、この体験の中でユーザーには一切見せません。

完成条件は「初見の人が、誰にも言われず自分から次を触りたくなること」です。

## 🌱のその直後 — 現実世界への往復（Scene 4 / RETURN）

「最初の10分」の確定済み体験（WHITE CANVAS → … → 🌱「ここから、すべてが始まる。」）に続けて、
芽が生まれた直後の体験を追加しています。ここは画面の中だけで完結せず、
**画面 → 現実 → 行動 → 画面へ戻る → 世界が変わる** という往復そのものが核になります。

```
🌱が生まれる（既存の確定済み体験）
↓
芽だけが静かに揺れる時間（何も表示しない）
↓
土の中から細い根が一本、静かに伸びる
↓
「では、ひとつだけ。」
↓
「今日、現実で何を動かしますか。」 ← ユーザーが自分で決めて入力する（例・選択肢は出さない）
↓
LOCK：「それを、やってきてください。」（「できた」ボタンは置かない。画面を閉じてよい）
↓
（ユーザーが現実で実際にそれをやってくる）
↓
RETURN：後で戻ってきたときに、自分で決めた一歩を静かに再表示する
↓
その下に初めて「動かした」という操作が現れる
↓
ユーザーが「動かした」に触れる
↓
派手な演出はなし。根がもう少し伸びる／茎がわずかに太くなる／葉が一枚増える
　→「回答したから成長」ではなく「現実を動かしたから成長」を身体で理解する
```

将来的に接続する53・守破離・F・Freedom Creator・既知領域／未知領域・行動履歴・成長履歴などは、
今回もユーザーには一切表示していません。内部状態として拡張できるよう、`state.internal`（下記）に
空のオブジェクトとして枠だけ用意しています。

### 保存される状態（localStorage）

キー：`daimuboku:v1:state`

| フィールド | 型 | 意味 |
| --- | --- | --- |
| `version` | number | 保存フォーマットのバージョン（現在 `1`） |
| `firstAnswer` | string | 最初の問い（給料が消滅したらどう生きるか）への回答 |
| `sprouted` | boolean | 🌱が生まれた状態まで到達したか |
| `todayAction` | string | ユーザーが自分で決めた「今日、現実で動かす一つ」 |
| `actionLocked` | boolean | その一歩を入力・確定し、LOCKされたか（まだ実行済みではない） |
| `actionDone` | boolean | 現実で実行し、「動かした」に触れたか |
| `growthStage` | number | 木の成長段階（`0`＝根と最初の2枚の葉のみ／`1`＝3枚目の葉・太い茎・深い根まで成長） |
| `internal` | object | 将来の53／守破離／F／Freedom Creator／既知領域・未知領域／行動履歴・成長履歴などの接続用の空の枠（現在は未使用） |

ページを閉じて戻っても、この状態から同じ地点で再開します。「動かした」を経ずに葉や根、茎が育つことはありません
（＝回答しただけでは成長せず、現実を動かしたときだけ木が育ちます）。

## ファイル構成

```
index.html      画面構造（Scene 1: WHITE CANVAS / Scene 2: LOCK / Scene 3: UNLOCK / Scene 4: 現実行動・RETURN）
css/base.css    基本スタイル（トークン・リセット）
css/style.css   このプロトタイプ専用のスタイル・アニメーション（3枚目の葉・根・RETURN画面を含む）
js/app.js       画面遷移・演出（欲望オブジェクトの出現、LOCK、UNLOCK、GET、成長シーケンス、現実行動のLOCK/RETURN/成長、localStorage保存、サウンド）
```

ビルド手順は不要です。すべて静的なHTML/CSS/JSのみで動作します。

## ローカルでの確認方法

Node.jsの `serve` などで配信して、ブラウザで開いてください。

```bash
npx serve . -l 3000
```

`http://localhost:3000` を開き、中央の点に触れるところから体験が始まります。
